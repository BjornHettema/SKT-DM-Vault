# Storm King's Thunder - DM Vault

Private Obsidian vault for running *Storm King's Thunder* (D&D 5e, 2014 rules) over Tabletop Simulator + Discord.

**This repository must stay PRIVATE.** It contains spoilers and page references to a copyrighted book.
PDFs are excluded by `.gitignore` and live only on the DM's computer in `_Sources/`.

Open `00 Home.md` in Obsidian to start.

| Folder | What goes in it |
|---|---|
| 00 Inbox | New, unsorted notes (Obsidian puts new notes here) |
| 01 Campaign | Overview, table rules, adventure flow, calendar, indexes |
| 02 Sessions | One note per session: prep, live log, recap |
| 03 Party | One note per player character (DM-only: secrets & hooks) |
| 04 Chapters | One note per book chapter with page links and prep checklist |
| 05 NPCs | People |
| 06 Locations | Places |
| 07 Factions | Organisations, and the giants' ordning |
| 08 Encounters | Prepared fights and set pieces (stat blocks, initiative) |
| 09 Handouts | Things you show players (with TTS image URLs) |
| _Templates | Note templates (Obsidian core Templates plugin) |
| _Sources | PDFs (local only - never committed) |
| _Attachments | Images pasted into notes |
