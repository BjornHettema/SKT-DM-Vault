# Campaign Calendar

The Realms use the **Calendar of Harptos**: 12 months of 30 days split into three tendays, plus festival days. The book explains tendays and the year numbering in the [[Storm Kings Thunder.pdf#page=14|sidebar on p. 13]].

**Recommended:** install the *Calendarium* plugin and pick the Harptos calendar if it's in the presets. If it isn't, build Harptos from this note.
Add an `ingame_date` to each session note so you always know how much time has passed. This matters for travel in chapter 3.
