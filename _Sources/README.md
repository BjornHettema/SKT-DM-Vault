# _Sources (local only)

Put your PDFs here. Everything in this folder except this README is ignored by Git, so it never goes to GitHub.

Move these files in here:

- `Storm Kings Thunder.pdf` (required - every page link in the vault points to it, and the name must match exactly)
- `Sword Coast Adventurer Guide.pdf`
- `2024 Monster Manual.pdf` (see the warning below)
- `Character Sheets/` - the four player sheets (`b'leep.pdf`, `shay rajulaegis (new).pdf`, `sylvaris.pdf`, `wolfram erenwald.pdf`)

Links such as [[Storm Kings Thunder.pdf#page=21|p. 20]] open the book at the right page inside Obsidian.
The PDF has one extra page at the front, so PDF page = book page + 1. The links already handle this.

> [!warning] 2014 vs 2024 Monster Manual
> Your table plays **2014 rules as written**, and *Storm King's Thunder* was written for the **2014** Monster Manual.
> The 2024 Monster Manual changes many stat blocks, including the giants. Use the 5e SRD 5.1 (2014) monsters built into the
> Fantasy Statblocks plugin, or a 2014 Monster Manual, so your fights match the book's balance.
